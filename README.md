# Noongar Language Explorer

## Project Overview

The **Noongar Language Explorer** is an interactive Python and Streamlit application developed for the CITS1501 Introduction to Programming project.

The application allows users to explore a published Noongar language wordlist through an English-to-Noongar dictionary, dataset analysis, related-word grouping, and an interactive quiz.

The application is intended for students and visitors who want to explore entries contained in the published wordlist.

Noongar language content is not generated by AI. The Noongar entries and English meanings displayed by the application come from the published dataset used by the project.

---

## Current Features

### Home

The Home page introduces the Noongar Language Explorer and provides navigation to the application's main features.

### English-to-Noongar Dictionary

The Dictionary allows users to enter an English word or meaning and find matching Noongar entries from the published dataset.

The search system:

* is case-insensitive;
* removes unnecessary surrounding whitespace;
* supports exact and partial searches;
* ranks exact matches before broader matches;
* returns multiple matching entries where appropriate;
* provides feedback when no results are found or the input is blank.

Search results are ranked in the following order:

1. Exact English meaning
2. English meaning beginning with the query
3. English meaning containing the query

### Data Explorer

The Data Explorer provides an interactive analysis of the published wordlist.

It includes:

* total dataset record count;
* number of unique Noongar entries;
* number of unique English meanings;
* application-defined related-word groups;
* an interactive bar chart comparing group sizes;
* identification of the largest defined group;
* a dropdown allowing users to explore entries within individual groups.

The current application-defined groups are:

* Animals
* Plants and Food
* People and Family
* Body
* Actions
* Nature and Environment
* Places and Position
* Time
* Objects and Shelter
* Descriptions and States
* Other

The groups are created by analysing keywords in the published English meanings. They are provided only as an exploratory feature and are **not official Noongar linguistic or cultural categories**.

The `Other` group is deliberately retained for entries that do not meaningfully match the defined categories.

### Interactive Quiz

The Quiz allows users to test their recognition of Noongar entries using English meanings from the published dataset.

For each question, the application:

1. selects a suitable English meaning from the dataset;
2. retrieves its corresponding Noongar entry;
3. selects three different Noongar entries as distractors;
4. prevents the correct answer from appearing as a distractor;
5. removes duplicate answer options;
6. randomises the order of the four options;
7. checks the user's selected answer;
8. provides feedback;
9. tracks the number of correct answers and questions answered.

The quiz uses Streamlit session state to maintain the current question and score while the user interacts with the application.

Users can also restart the quiz at any time. Restarting:

* resets the number of correct answers to zero;
* resets the number of answered questions to zero;
* clears the previous answered state;
* generates a new quiz question.

English meanings containing obvious unsuitable quiz markers such as question marks or emphasis annotations are excluded from question selection.

The quiz also handles invalid interactions, such as attempting to check an answer without first selecting an option.

## Dataset

The project uses a CSV dataset containing **275 records**.

The dataset contains the following columns:

* `noongar`
* `english`
* `source_url`

Dataset validation found:

* 275 records;
* no missing values in the current dataset;
* no duplicate complete rows;
* one repeated Noongar entry.

The repeated Noongar entry was retained because the records contain different English descriptions and therefore should not automatically be treated as duplicate data.

## Data Source

The language data used by this project is sourced from the Wirlomin language list:

https://www.wirlomin.com.au/language-list/

The project uses the published dataset as its authoritative source for Noongar language content.

The application does not use AI to generate Noongar words, translations, cultural information, or historical information.

Usage, attribution, copyright, and access conditions for the source will be reviewed and documented as part of the final project documentation.

## Installation

Clone the repository and move into the project directory.

Create and activate a Python virtual environment if required.

Install the required packages:

```bash
python -m pip install streamlit pandas pytest
```

Alternatively, install the dependencies from `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

---

## Running the Application

From the project directory, run:

```bash
python -m streamlit run Home.py
```

Streamlit will provide a local address that can be opened in a web browser.

## Manual Testing

Development check scripts are currently used to verify major functionality.

### Dataset Validation

Run:

```bash
python check_data.py
```

This is used to check:

* the dataset loads correctly;
* the expected columns are present;
* the dataset contains at least 200 records;
* missing values and duplicate rows can be inspected.

### Dictionary Search

Run:

```bash
python check_search.py
```

This is used to manually test:

* exact English searches;
* partial searches;
* case-insensitive input;
* surrounding whitespace;
* multiple matches;
* no-result searches;
* blank input handling.

### Related-Word Analysis

Run:

```bash
python check_analysis.py
```

This is used to inspect:

* application-defined category assignments;
* group counts;
* entries placed in the `Other` category;
* possible misclassifications that require refinement.

### Quiz Question Generation

Run:

```bash
python check_quiz.py
```

This is used to verify that:

* exactly four answer options are generated;
* the correct answer is included;
* all answer options are unique;
* unsuitable English prompts are filtered out.

The Streamlit Quiz page has also been manually tested to confirm that:

* correct answers display appropriate feedback;
* incorrect answers display the correct answer;
* feedback is not duplicated;
* the score updates correctly;
* the Next Question button generates another question;
* attempting to check an answer without selecting an option gives a warning;
* the Restart Quiz button resets the score to `0 correct out of 0 answered`;
* restarting generates a fresh quiz question.

Automated `pytest` tests will be added later in development.
