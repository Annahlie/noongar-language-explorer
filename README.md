# Noongar Language Explorer

## Project Overview

The **Noongar Language Explorer** is an interactive web application developed for the CITS1501 Introduction to Programming with Python project.

The application is designed to help users explore a published Noongar wordlist. Users can search using an English word or meaning and discover matching Noongar entries.

The application is being developed using **Python**, **Streamlit**, **Pandas**, **Git**, and **GitHub**.

## Intended Users

The application is intended for people interested in exploring published Noongar language material in an accessible and interactive way.

The application does not generate Noongar language or cultural information. Language information displayed by the application comes from the published dataset identified below.

## Current Features

The application currently includes:

- A multi-page Streamlit interface
- Home page
- English-to-Noongar dictionary
- Case-insensitive searching
- Input whitespace handling
- Ranked search results
- Exact, starts-with, and contains matching
- Support for multiple matching results
- Feedback for empty searches
- Feedback when no results are found
- Dataset loading from a CSV file
- Dataset validation and error handling
- Dataset summary information
- Wordlist browser
- Source information for dictionary results
- Displays summary statistics for the published wordlist.
- Analyses English meanings using an application-defined keyword grouping algorithm.
- Groups related entries into categories including Animals, Plants and Food, People and Family, Body, Actions, Nature and Environment, Places and Position, Time, Objects and Shelter, and Descriptions and States.
- Retains an Other category for entries that do not meaningfully match the defined groups.
- Displays an interactive bar chart comparing the number of matched records in each group.
- Identifies the largest defined group in the dataset.
- Allows users to select a group and explore the matching English and Noongar entries.
- Clearly identifies the groups as application-defined exploratory categories rather than official Noongar linguistic or cultural categories.

## Dataset

The application currently uses a published dataset containing **275 records**.

The CSV file contains three columns:

* `noongar` — the published Noongar entry
* `english` — the published English meaning or description
* `source_url` — the URL identifying the source of the entry

Initial dataset validation found:

* 275 records
* 0 missing values
* 0 completely duplicated rows
* 1 repeated Noongar entry

The repeated Noongar entry was not automatically removed because separate records may contain different meanings.

## Data Source

The language data used by the application was obtained from:

Noongar language or cultural information is generated by AI for inclusion in the dataset.

## Dictionary Search Algorithm

The dictionary allows the user to enter an English word or meaning and find matching Noongar entries.

The search algorithm is implemented in `src/search.py`.

Before searching, the user's input is normalised by:

1. checking that the input is text;
2. removing surrounding whitespace; and
3. converting the text to lowercase.

The algorithm then loops through the English meanings in the dataset and ranks matches in the following order:

1. exact matches;
2. meanings that start with the search query; and
3. meanings that contain the search query elsewhere.

This allows searches to work regardless of capitalisation and provides useful partial matches when an exact meaning is not available.

## Installation

Python 3 is required to run the application.

Clone or download the repository and open the project directory.

Install the required Python packages using:

```bash
python -m pip install -r requirements.txt
```

## Running the Application

From the main project directory, run:

```bash
python -m streamlit run Home.py
```

Streamlit will start a local web server and provide an address for opening the application in a browser.

## Using the Dictionary

1. Open the **Dictionary** page using the Streamlit navigation.
2. Enter an English word or meaning, such as `water`.
3. Select **Search**.
4. The application searches the published English meanings.
5. Matching Noongar entries and their original English descriptions are displayed.

The dictionary also handles uppercase input and surrounding whitespace.
